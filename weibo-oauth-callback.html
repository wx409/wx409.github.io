微博开放平台 · 授权回调页

本页仅用于接收 OAuth 授权码，不收集、不上传任何数据（noindex）。

  1. 下方是微博返回的授权码 code（复制它）
  2. 在你的电脑上执行：
    python -X utf8 微博开放API.py --code <粘贴的code>
  3. 看到「已保存 token」即完成授权，之后跑 --fetch 即可采集。

提示：授权码一次性且短时有效。若过期，重新执行 python -X utf8 微博开放API.py --auth-url 再授权一次即可。
