## 一、为什么重算

现网「巡演带动效应」等图表给的是单点百分比（+8.3%、+70.4%），没有区间、没有样本量，且内部存在两套互不一致的基线：

- `total_uplift` 用 `T-21…T-7` 当基线
- `daily_series` 用 `T-7…T-1` 当基线

同一场演出两个数不可横向比较；`event_study.json` 只落盘了 T+1…T+14，没有事件前窗口，**预趋势无法检验**。

## 二、换了什么

| 环节 | 原来 | 现在 |
|---|---|---|
| 面板 | 网页 JSON 的稀疏 `points` | 最新一份 raw 全量快照（148 MB，292,773 条，1284 天） |
| 基线 | 21 天前 / 7 天前混用 | 明确声明，并给出 4×2 口径敏感性矩阵 |
| 对照 | 全站曲目池均值 | **同一场**未演唱曲目（场级共同冲击被吸收） |
| 不确定性 | 无 | 事件级 bootstrap 4000 次，报 95% CI |
| 预趋势 | 无法检验 | 短窗联合检验 p=0.844；长窗 p<0.001（据此拒绝长基线） |

## 三、结果

### 3.1 逐日曲线（同场 DiD，基线 T-7…T-1，等权场次）

| 相对日 | 效应 | 95% CI | 场次 |
|---|---|---|---|
| T+0 | +7.0% | 0.8 … 14.7 | 38 |
| T+1 | +7.0% | 1.6 … 13.0 | 44 |
| T+2 | +7.9% | 2.6 … 13.4 | 45 |
| T+3 | +2.9% | −2.3 … 8.4 | 46 |
| T+7 | +0.3% | −6.8 … 8.3 | 42 |
| T+14 | +2.8% | −4.0 … 10.7 | 42 |

首周平均 +3.7%。**效应集中在前 3 天，一周内消失。**

### 3.2 口径敏感性（8 种组合）

DiD 在 **+2.0% ~ +7.4%** 之间；只有「基线 T−7…T−1 × 事后 0…6」这一种的 95% CI 不含 0（+4.0%，0.4–7.8）。

→ 结论：**方向稳定为正，量级小且对口径敏感**。现网 +8.3% / +70.4% 属于长基线或极端场次的产物，不能当普遍结论。

### 3.3 异质性（n≥6 组，首周）

- 内容类型：其他 +15.4%（8 场）｜个人巡回 +1.5%（23 场）｜拼盘 −4.2%（6 场）
- 城市层级：其他 +7.3%（8）｜一线 +3.5%（28）｜新一线 +2.5%（10）

「个人巡回」几乎不带动曲目池，与直觉相反但方向稳健；小样本组（n=6/8）只作参考。

### 3.4 唱功证据（录音室 72 首，同一管线）

| 指标 | 值 |
|---|---|
| 最低稳定音 | 最低 61.5 Hz（B1）｜p10 65.3｜中位 77.7（≈E♭2）｜p90 96.5 |
| 落在 B1±50 音分 | **4 / 72 首** |
| 低于 C2 | 8 / 72 首 |
| 音域跨度 | 2.15 八度（95% CI 2.03–2.27）｜≥2 八度占 59% |

→ **B1 是代表作级极值，不是常规音区**。官方文案若写「音域下探至 B1」成立，但写成「常规演唱到 B1」不成立。

### 3.5 现场层：先清洗，再谈结论

现场层 840 行里：单曲单场 461 行、整场合计 83 行、曲名缺失 296 行。且现场走的是另一条测量管线（场次音频实测）：

| | 录音室 | 现场 |
|---|---|---|
| 每曲最低音中位 | 77.7 Hz | 87.1 Hz |
| 跨度中位 | 2.23 八度 | 2.70 八度 |

两边同时出现「最低音更高、跨度更大」，这是**管线系统差异**（混音、伴唱、扩声、饭拍音质）的典型形态，不是唱功差异。要下现场结论，需先满足：单曲单场粒度、同管线同参数、每曲 ≥3 场、注明场地与音源。

### 3.6 清洗后的现场稳定性（唯一站得住的「稳」）

840 行现场记录清洗后：**单曲单场 460 行 / 116 场**（剔除空曲名 296、整场合计 83），同场重复测量取中位，每曲 ≥3 场得 25 首、≥4 场得 18 首。

| 指标 | 值 |
|---|---|
| 同曲跨场最低音 SD | 中位 **2.34 半音（234 音分）**，p75 2.95 |
| 跨场极差 | 中位 4.75 半音 |
| ICC(1)（曲目间方差占比） | **0.33**（95% CI 0.13–0.54） |

ICC 0.33 的含义：只有约三分之一的方差在「曲目之间」，其余来自场次、音源与扩声——**所以整体不能下「稳」的结论**。

但有三首在 4 场以上仍把波动压在 1 个半音内：

| 曲目 | 场次 | 中位最低音 | 跨场 SD |
|---|---|---|---|
| Your Man | 11 | 90.4 Hz | **0.22 半音** |
| 新不了情 | 4 | 88.6 Hz | 0.66 半音 |
| 让她降落 | 7 | 92.1 Hz | 0.98 半音 |

论证方式很关键：**测量噪声只会放大波动，不会制造稳定**。所以这三首的低波动是保守证据，可以写成「个别曲目现场音区极稳」；但不能外推成「整体现场音域」或「现场比录音室差几个半音」。

## 四、测量不确定性（引用站内自己的诊断）

- 双引擎（自研 YIN / Praat）在 ±50 音分内一致的帧：录音室 **69.1%**、现场 **58.5%**
- `data/derived/engine_disagreement.json` 自标 `publishable: false`
- 因此 B1 应写作 **B1 ± 50 音分（≈60.0–63.5 Hz）**，不要给到小数点后一位

## 六、局限（写在最前面，别藏）

1. 指数是平台相对值，不是收听人数绝对值；跨年比较受平台改版影响。
2. 日期缺 123 天、46 段断档；26 处场次间隔 <7 天，窗口重叠（已用同场对照 + 事件聚类缓解，未根除）。
3. 「被演唱」的定义依赖歌单长表，歌单不全时处理组会漏。
4. 结论对基线窗口敏感——这正是要展示敏感性矩阵的理由。
5. 现场层未清洗完成，本轮不出结论。
