# 迁移步骤（旧机 → 新笔记本）

> 前提：两个脚本在 `D:\wx409.github.io\migrate\`。U 盘里已有 `DSH\.dsh` 与 `D:\wx409.github.io`、`E:\wx\...` 的副本。

## 一、新机准备（先做，别急着拷文件）

1. 装 **DSH 桌面端**（先别登录）
2. 装 **Python 3.10**、**ffmpeg / ffprobe**、**git**
3. **确认盘符是 D: 和 E:**
   ```powershell
   Get-Volume | Where-Object DriveLetter | Select-Object DriveLetter,FileSystemLabel,@{n='FreeGB';e={[math]::Round($_.SizeRemaining/1GB)}}
   ```
   脚本内大量硬编码 `D:\wx409.github.io`、`E:\wx\...`；盘符不同会全线失效。

## 二、放文件

1. **退出 DSH 进程**
2. `U盘\DSH\.dsh` → `D:\DSH\.dsh`（若已存在，先改名 `.dsh.bak`）
3. `D:\wx409.github.io`、`E:\wx\...` 按原结构放回
4. 启动 DSH，检查设置/技能/插件是否都在
5. **最后**再登录同一账号（先有文件、后有会话，避免路径对不上）

## 三、重建系统级项（文件带不走）

- 11 个计划任务（`wx409_*` + `QQMusicDashboardAutoStart`）
- 启动文件夹：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\wx409_social_boot.cmd`
- **重新抓 cookie**（勿两机共用同一份，会触发风控）

## 四、跑验收

双击 `migrate\验收_迁移后.cmd`，逐项检查：
- 关键路径 / Python / ffmpeg / git
- 九项审计逐 0
- 计划任务是否齐
- 关键数据文件是否存在 + **抽样 sha256**（与旧机对比应一致）
- `audit_live` 线上核验

## 五、旧机交接前清理

双击 `migrate\清理_交接前.cmd`（需输入 YES → DELETE 两次确认），删除全部凭据文件；随后手动：
1. 退出所有账号登录
2. 浏览器清密码与 Cookie
3. GitHub 吊销 token / 移除 SSH key
4. 建孩子账户，迁移或删除你的账户数据
5. 视情况删除听辨样本、场次音频等私域素材

## 六、已知注意

- `.dsh` 里的 `sessions\ logs\ cache\` 属运行时产物，**不要迁**（两机同时登录会打架）
- U 盘拷贝卡住多因 `.db`/日志被占用 → 用 `7z a -mx1` 打包成单文件再拷
- 大素材（音频/视频，约 330 GB）可不迁，日后按需重下
