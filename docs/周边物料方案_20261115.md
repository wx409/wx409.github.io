### 5.2 页面内含

B站 播放器 + 站内音域实测（多听有益 2.97 八度 / 微醺 1.59 / 在路上 3.10）+ 出处链接 + `MusicRecording` 结构化数据。

### 5.3 写入步骤

1. 手机装 **NFC Tools**；
2. 写入 → 添加记录 → **URL**；
3. 粘贴上面任一条 URL（英文/中文均可，自动百分号编码）；
4. 贴片靠近手机写入；
5. 贴在底座 Ø22.4 腔内，滴 UV 胶/502 封边。

**优势**：链接固定，页面内容随时更新，**卡片不用重写**。

## 六、装配流程

```
① 打印 mic_voxel_55.stl（45–55 min）
② 打印 nfc_base_30.stl（12–15 min）
③ 打磨：400 目去毛刺（挂绳孔、磁铁槽边缘）
④ 压磁铁：背面 Ø10.2 槽 → Ø10×2 磁铁（N/S 面统一朝外）
⑤ 穿钥匙圈：底部 Ø3.2 孔
⑥ 写 NFC → 放入底座 → 封胶
⑦ 麦克风插到底座 Ø12.8 凹槽（可拆）
```
