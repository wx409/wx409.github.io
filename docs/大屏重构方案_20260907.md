# 大屏（dashboard）重构方案 · v1（2026-09-07）

> 目标：把"30+ 平铺区块、自动分析文案乱插、文本档案太浅"整合成**分层、可折叠、口径带横幅**的档案型大屏。
> 数据已就位：`data\archive_baseline.json`（统一口径+基线，可展示）+ 档案卡（`论文素材_王晰作传\档案卡\`）。
> 现状来源：`dashboard\index.html` 区块标题（139KB 生成物）+ `dashboard_data.json`（3.5MB）。

## 一、现状的问题（"乱"在哪）

1. **平铺 30+ 区块**：热度/事件研究/作品生态/分析文案在同一层滚动，无分组、无层级。
2. **自动分析文案（📈数据自动分析/🎯行动建议）穿插在数据块中间**，与硬数据混排，主次不清。
3. **📚文本档案太浅**：只有 text_archive.json 的聚合计数（城市/情绪/常青曲），无出处、无事件级。
4. 无数值口径横幅：读者不知"池≠全站"、哪年可量化。

## 二、目标结构（分层 + 分组折叠 + 口径横幅）

```
┌ 顶部·口径横幅（一行，常驻）──────────────┐
│ 主口径: 追踪曲目池日均(≥2首) 2023-01~今  非全站   │
│ 可量化实证窗口: 2023+ ；早年(2007-22)仅定性      │
├ 核心结论卡（3-4 张，人工维护口径）─────────┤
├ ① 热度层（可折叠）────────────────────┤
│  近7日/历史趋势/TOP对比/异常/收听(同口径注)│
├ ② 事件研究层（可折叠）────────────────┤
│  修基线后 CAR 曲线 + 事件效应表(v2, 含na) │
├ ③ 作品生态层（可折叠）────────────────┤
│  成长流转/衰减带/时间偏好/老歌复活 等      │
├ ④ 文本档案层（可折叠，本次重点升级）──────┤
│  阶段档案卡(4阶段摘要+跳转) → 事件档案卡   │
│  (2024发行大年卡: 履历/原话/指数窗口/关联) │
│  + 语料印证(原话带 date+source)          │
├ ⑤ 口径与数据底账（可折叠）──────────────┤
│  读 data/archive_baseline.json：年度表 + │
│  修基线说明 + 脚本路径(可复算)            │
└───────────────────────────────────────┘
```

要点：分组可折叠、默认折叠"深水区"、分析文案移入各分组尾部、口径与"可量化 vs 仅定性"始终标清。

## 三、落地步骤（两步走，先可见后大改）

**Step 1（小改·先上）**：在 `dashboard\index.html` 顶部加"口径横幅"，并把 `data/archive_baseline.json` 渲染为「口径与数据底账」区块（年度表+修基线说明+12 条事件效应，na 灰显）。
**Step 2（重构·大改）**：改生成器 `project_b\QQ音乐大屏生成器_GEO优化版_源码.py`：
1. 输出结构改为上表 5 层（用 `<details>` 折叠分组，默认展开 ①②，折叠 ③④⑤）
2. 自动分析文案收进各组尾部，与数据块分容器
3. 📚文本档案改为读**档案 digest**（阶段档案/事件档案卡标题+摘要+链接），不再用聚合计数充数
4. 生成后跑三查：分组数、口径横幅在位、无裸 CSS（沿用 dashboard CSS 修复纪律）

## 四、Step 1 校验口径（防回退）

- `data/archive_baseline.json` 已在站内（git 跟踪）；改完 push 后硬刷 dashboard。
- 事件效应数字一律来自 `论文素材_王晰作传\基线口径\compute_baseline_v1.py`（na 不显示百分比）。
- 任何新数字入屏前：写进 compute 脚本 → 再复制 json，**禁止手改 json 进屏**（可复算纪律）。
