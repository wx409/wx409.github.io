# 场次声学切分与歌手归属方法论（v1 · 2026-10-10）

> 适用：**含 talk / 主持 / 观众 / 器乐段的场次素材**，尤其是双人或多声部同台（如《沉响与长歌》王晰 × 傲日其愣）。
> 单一事实源：`data/calibers.md` 的 id **`show_block_attribution`**；落地数据 `data/show_blocks/*.json`。
> 由来：2026-10-09 北京场三轮人耳定案（80 点）＋ 一次方法学更正。**本文件是过程方法的归档，不是对外内容。**

## 一、为什么需要这套东西（踩过的坑）

| 坑 | 现象 | 教训 |
|---|---|---|
| 把「按歌单顺序推定」当切分 | 19 段整段当演唱，曲名全按歌单安放 | 歌单**顺序不等于录音顺序**（本场英文串烧与民族串烧先后与人耳相反） |
| 单曲直拍当演唱起点 | 直拍对齐处实测是 talk | **单曲直拍含 talk 前导**：锚点只标「内容出现位置」，不是起唱点 |
| 全局语料混入他场 | 北京场报告里出现 8.23 广州曲目榜与代表性句子 | 聚合器读了**未按场次过滤**的全局语料（`temp/_xhs_classified.json`、`xhs_archive/按链接`、`_gz_quotes.json`）→ 必须加「本场专属信号」硬过滤 |
| B站条目整批丢失 | 聚合器只认 `text` 字段，B站采集产物是 `title`/`desc` | 采集字段与分析字段不一致时，**先核对字段名**（本场 14 条 B站全丢） |
| 极值音当成能力 | 「某人唱到 X Hz」 | 见 §4：**极值音的歌手归属在现有条件下不可判定** |
| 松门取极值 | 最低音虚假下探 4–13 个半音 | 一律以严格门为准，同时保留松门对照 |

## 二、切分

### 2.1 融指纹滑动相关对齐法（可用于「直拍 ↔ 全场」）

把带归属的单曲直拍与全场分段放在同一条绝对时间轴上，用**原始混音 5 维特征**
（每秒 1 帧：RMS / 谱质心 / 谱平坦度 / 高频比 / 过零率）做滑窗相关：

- 取相关性峰的 offset；同时算「最优 vs 次优（±90s 邻域外）」的**边际**；
- **边际 >0.20** 才算可信锚点（本场：敕勒歌 & 乌兰巴托 +0.403、小毛驴 +0.286、哭砂 +0.250）；
- **边际 <0.05 的一律不用**（本场心恋 +0.048、美酒加咖啡 +0.020 → 保持待核）。

### 2.2 实测失效的方法（不要重复尝试）

- **音符序列匹配**（音级+时长的滑动匹配）：本批最佳 0.09–0.5，无判别力；
- **chroma / 音级直方图匹配**：被伴奏与分离残留淹没，最优分与次优分几乎无差；
- 原因猜测：手机实录信噪比低 + demucs 分离残留多 + 现场即兴装饰音改变了音高轨迹。

### 2.3 分区规则（人耳锚点驱动）

1. 人耳定案点分四类：**演唱**（附歌手）/ **talk** / **伴奏·配乐·无演唱** / **不可归属**（重叠合唱、观众唱）/ **非演唱发声**（口哨等）。
2. 非演唱点 **±8 秒为硬排除区**（口哨因前后仍为演唱，取 ±4s）。
3. 相邻演唱点之间按**中点**划界（中点落入排除区则取排除区边界）。
4. 相邻且同歌手的块合并；补集即「非演唱 / 未定区」（**程序化求补集**，不手工列举，避免漏段）。
5. 时长 <60s 的块只作记录，不进指标。

## 三、四判据 + 一 QC（对外数字必须全过）

| 判据 | 内容 | 性质 |
|---|---|---|
| ① 严格门 | 时长 ≥0.20s、HNR ≥8dB、强度 ≥音符中位−12dB | 排除规则 |
| ② 原始混音谐波列 | ≤C2 读数须在**原始混音**上 1f0/3f0 成立 | 排除规则 |
| ③ 归属判据 | 最低读数距**块内音区中心** ≤13.5 半音 | **仅「存疑标记」→ 触发人耳复核；禁止自动排除** |
| ④ 分离质量 QC | 逐秒人声轨/混音 **5 频带谱形距离**（总变差）；直通占比 >35% → 判「分离大量直通」，整块排除 | 排除规则 |

> ③ 为什么不能自动排除：手机实录里「比演唱音区低一两个八度」既可能是器乐残留，**也可能是歌手真实的低音**；
> 实测确有被标记却仍无法证伪的情形 → 一律记 `归属未定`，**既不加冕也不排除**。
> ④ 的由来：实测在无演唱时段 demucs 会**原样直通混音**（人声轨与混音电平相同、5 频带分布逐项一致），
> 此时任何读数都是「混音的读数」——**只靠收紧门拦不住**（talk 同样响、同样稳）。

## 四、极值音归属的可判定边界（本方法论的结论）

| 手段 | 能证明 | **不能**证明 |
|---|---|---|
| ① 严格门 | 这是一个稳健的准周期声学事件 | 不含身份信息；器乐持续音同样满足 |
| ② 谐波列 | 该频率是真实基频（非次谐波/倍频误锁） | **不含身份信息**——贝斯/大提琴同样有完整谐波列 |
| ③ 距音区中心 | 该读数与块内分布距离过远 | 只是统计先验；距离远也可能是真实低音 |
| ④ 分离 QC | 分离是否有效 | 即使有效，也分不开「人声」与「同频段器乐」 |
| ⑤ 人耳 8 秒片段 | 该时间窗内**有人声 / 大致是谁 / 唱还是 talk** | **不能**把某一帧的极值音钉到某个人（片段嘈杂） |

**结论**：在**同时**具备「**同刻多源** ＋ **更强分离** ＋ **音色/共振峰特征**」三条之前，
**极值音的歌手归属不可判定** → 一律标 `归属未定`，不得写「某人唱到 X Hz」。

**升级路线（尚未执行）**：
1. 更强分离：`htdemucs_ft` / 6 轨模型 + 以贝斯·鼓轨做反相抵消；
2. 音色判据：对候选极值音窗口算 **F1–F3 共振峰 + 谱倾斜**，与该歌手同场其他块的分布做距离比较；
3. **同刻多源**：找同场第二路录音，对同一时刻做两路一致性——同场同曲双源是最强归属证据；
4. 官方音源：若有官方现场录音/发行版，直接复测同一句；
5. 均不可得 → 保持 `待核`（宁可缺值，不给错值）。

## 五、换门对照（必报两套）

同一段音频，**松门（HNR≥5dB、≥0.15s、强度≥中位−25dB）** 相对严格门普遍把最低音**下拉 4–13 个半音**，
下探值多落在 60–85Hz（手机实录最不可靠区）。因此：
- 结论一律以**严格门**为准；
- 报告里**同时给出松门值**作为方法学对照（示例：某 400s 块严格门 B2 124.0Hz / 松门 D#2 77.2Hz）。

## 七、反馈采集口径（配套纪律）

- 「本场内容」判定：必须命中**剧名 / 场馆 / 日期**之一，且含主体词；命中他场反证词（其他城市/场次）且无强信号者剔除。
- 采集与分析**字段名必须对齐**（`text` vs `title`/`desc`）。
- 全局归档语料（`_xhs_classified.json` 等）**不得直接进单场统计**。
- 小红书/微博风控失败**不算致命**，但必须在产物里如实标注各平台条数。
- 工具：`project_b/recollect_show_feedback_strict.py`（收紧 + 备份旧批次 + 输出前后差异）。

## 九、升级子集的执行结果（2026-10-10 实测补记）

| 升级手段 | 执行情况 | 结论 |
|---|---|---|
| ③ 同刻多源 | ✅ 已执行（6 条同场同曲直拍；仅用边际 ≥0.20 的参照源） | 18 块中 **2 块**获「同刻多源支持」（b05 王晰 B2 122.3Hz、b06 傲日 D#3 157.7Hz） |
| ① 更强分离 | ✅ 已执行（`htdemucs_ft`；**必须从原始混音切片**——块音频已是人声轨时重分离等于空转，会得到直通 1.00 的假象） | 两处直通块恢复可用（0.40/0.53 → 0.26/0.26）；**但换引擎使极值读数改变约 4 个半音** → 仍不可归属 |
| ② 音色/共振峰 | ✅ 已执行（谱质心 / 谱倾斜 / 低频占比 的模板区间比对） | **无判别力**：王晰与双人模板区间高度重叠，目标随机落区 |
| ④ 官方音源 ⑤ 保持待核 | 未执行（无素材） | 维持 `待核` |

**净结论**：「同刻多源」是唯一有效方向，但本场只覆盖 2 块；三条手段无一条能单独证明极值音的歌手归属
→ 「极值音归属不可判定」口径继续成立。
