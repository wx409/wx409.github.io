## 八、按需求找数据的顺序

1. **找一句话/一个视频** → 270 全文搜索（先跑 269 重建）
2. **找某首歌的所有版本** → 270 加 `--song 曲名`
3. **找现场演唱** → `project_b\query_stage.py`
4. **找录音室实测** → `data\archive_vocal_albums.json` / `…\专辑音域汇总.json`
5. **找原始微博** → `weibo_merged\合并`（主）或 少城 `index.json`
6. **找抖音原片** → `…\抖音\<日期>_<id>.mp4`

## 九、采集坑位（别再试）

| 来源 | 现象 | 已试过 | 结论 |
|---|---|---|---|
| 央视网 snow-book 文章页 | HTML 无正文 | 页面内无 JSON；`snow-book/api/getArticle`、`snow-book/api/article`、`api.cntv.cn/NewArticle/getArticleById` 均返回空/无内容 | **JS 壳，正文只在客户端**；转引用新浪转载/原微博 |
| 微博 1080p 视频（f.video.weibocdn.com） | HTTP 403 | 换 UA / 加 Referer / 带 Cookie 均 403 | 需微博会员；本地留 720p（带 Referer 可下） |
| 微博 repostTimeline | 未登录返回 `ok:-100`；登录后每页仅 6 条 | wb.txt 登录态可取样本，total_number 正常 | 想要全量转发明细需网页端滚动，API 不给全量 |
