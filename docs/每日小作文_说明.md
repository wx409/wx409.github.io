# 每日小作文：本地留存与阅读

## 网页

- 今日 + 最近 7 天：https://wx409.github.io/today.html
- 首页顶部有“今日新入库”条，指向该页。

## 本地灵感库

```
E:\wx\私有工具\每日小作文\
├── YYYY-MM-DD.md    ← 直接看/复制，适合当微博、小红书的初稿
└── YYYY-MM-DD.json  ← 结构化版本（分段、测量、标签）
```

每天 10:10 的 `bili_daily_ingest` + `build_today` 会自动生成；12:10 的 `today_watchdog` 检查是否真的更新。

## 内容结构

- 一段当天的小作文（有声音细节，不是通稿）；
- 当天声学测量摘要（曲目、最低稳定音、跨度、稳定性）；
- 标签；
- 没有新视频时，自动翻一首旧歌重听，明确标“旧证据重听”。
