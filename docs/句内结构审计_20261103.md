# 句内结构审计（2026-11-03）

> 目的：把上一版“低音落在句中”的结论降级为**待核观察**，并留下可复查的规则与清单。

## 一、规则（随结果保存）

| 项 | 规则 |
|---|---|
| 帧 | 逐帧 F0（hop 512 @44.1k ≈ 11.6ms） |
| **段** | 帧间隔 >0.3s 切段；称 **「自动分段」**，**不等同乐句/句子** |
| 低音定义 | 全曲 MIDI 的 **P10 及以下** |
| 句尾方向 | 段末 8 帧中位 − 段末前 16–30 帧中位 |
| 纳入门槛 | 帧数 ≥200、自动分段 ≥5 |

## 二、纳入与排除

| 项 | 数量 |
|---|---|
| 纳入 | **84 首**（每首取分段数最多的一条 F0 文件） |
| 排除 | 1 首（原因已记录在 `data/phrase_structure_audit.json`） |
| 低音事件总数 | **11,657** |

## 三、低音位置分布（不是中位数）

| 段内相对位置 | 占比 |
|---|---|
| 0–0.25（前段） | **30.2%** |
| 0.25–0.5 | 23.5% |
| 0.5–0.75 | 28.3% |
| 0.75–1.0（末段） | **18.1%** |

**两种汇总口径**：

| 口径 | 低音位置中位 | 句尾方向中位 |
|---|---|---|
| 逐曲等权 | 0.49 | −0.03 半音 |
| 逐事件汇总 | 0.468 | −0.03 半音 |

## 四、结论（严格版）

> **在本轮纳入的 84 首作品、当前自动分段规则下，低音读数的段内相对位置中位数为 0.47–0.49；
> 分布接近均匀、略偏前段（前 1/4 占 30.2%，末 1/4 占 18.1%）。
>
> 这一结果不支持“低音总在段尾收尾”的概括；
> 同时也不足以支持“低音集中在句中”——分布是铺开的。**

**上一版“低音落在句中、后半句托住”的说法作废**，它是叙事解释，不是统计结果。

**仍未解决**：

1. 自动分段是否对应实际乐句——需人工核对抽样；
2. 低音在**前段**偏多，可能是“起句就下潜”，也可能是分段把伴奏尾音并进来；
3. 人声归属在少数曲目仍需复核。
