# 内容维护：本周精选（一条命令）

## 操作中心

打开 `操作中心.bat` → 输入 **279**：

1. 先列出瞬间库编号（q 金句 / s 现场 / m 路人梗）；
2. 输入 5 个编号，例如：

```
q01 s03 m02 q07 s01
```

3. 脚本自动重建 `moments.html`、写入 `data/moments_picks.json`、commit + push。

## 命令行等价

```bat
cd /d D:\wx409.github.io
python -X utf8 project_b\pick_moments.py --list
python -X utf8 project_b\pick_moments.py q01 s03 m02 q07 s01
```

## 结果

- 页面顶部出现 **★ 本周精选**；
- 自动保留到下一次标注；
- 每天 11:20 的自动刷新会保留精选，不会被算法排序冲掉。

## 说明

- 编号来自当前 `data/moments.json`，每周刷新后可能变化；
- 不确定就先跑 `--list`，不要凭记忆；
- 不要手改 `moments.html`，会被重建覆盖。
