## 三、三处必改的具体改法

1. **八张专辑 → 七张专辑 + 一张数字 EP《回望》**
   《回望》2021-12-23 发行，3 首，未出实体，只有 QQ 音乐数字版。全站已按此改（页面由 `project_b/album_catalog.py` 从 `albums.json` 派生）。
   建议句式：「七张录音室专辑加一张三首的数字 EP」。

2. **「2021 杭州现场」→「2024 杭州（四巡/肆益）」**
   2021-11-27 那场是杭州签售会，留下的是《游离》A#1 57.8Hz；《多听有益》的 C2 读数来自 2023—2024 四巡（上海生日 65.2 / 杭州 65.4 / 北京 65.3）。

3. **六轮稳定性 6.45—7.5 → 6.4—7.4**
   实测：一巡 7.35、二巡 6.60、三巡 6.60、四巡 7.20、五巡 6.40、六巡 7.40 音分。

## 四、一处建议删

**F5「0.79 秒」**。F5 706.0Hz 与「人耳确认是王晰本人」都有据；但逐帧复算 690—720Hz 区间，累计 3.11 秒、最长连续仅 0.23 秒，**0.79 秒不是一个可复现的稳定段**。
建议改成：「《带着一颗好心去流浪》中被听辨确认为本人声部的 F5（706.0Hz）读数」——不写时长；或写「多次短暂触达」。

## 五、可补强的三处（数据已在库，但两篇都没用）

1. **舞台比录音室更稳**：专辑 vs 舞台音符内稳定性 6.85 vs 5.60 音分（p=0.001），舞台上反而更稳——这条比「稳」的形容词有力得多，也直接支持第二篇的标题。
2. **「低音是亮的」**：低/中音区频谱质心比，原始混音中位 0.996（《悬念》1.27）；同管线对照赵鹏低音区质心是他的 1/3.2、>1kHz 能量占比 1/4.5。第一篇文章第六节说「不能凭频谱质心给音色盖棺」是对的，但站内其实有对照组，可以写成「有条件支持」。
3. **极值重音区（过山车）**：相邻音符差 ≥12 半音且间隔 ≤0.5s，全库中位 2.04 次/分，最高 8.49（《美丽的草原我的家》Live）；《在路上》有 C#3→A5→A2 的 0.2 秒三连。第一篇文章第五节可以把这个「灵活性索引」落到实处。
