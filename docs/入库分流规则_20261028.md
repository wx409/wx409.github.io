# 入库分流规则（2026-10-28）

> 原则：**官方源不等于"什么都直接入库"**；按内容性质落到对应板块，走各自原有管道。
> 自动化的边界：能结构化的（新歌时间轴）自动；需要人工字段的（场次/场馆/卡司）仍进候选箱。

## 一、按内容类型分流

| 内容性质 | 判定词（示例） | 落点 | 是否自动 |
|---|---|---|---|
| **新歌发行** | 新歌 / 单曲 / 发行 / 上线 | 时间轴（type=album）+ `songs_meta` | **官方源自动**；粉丝源进候选箱 |
| **演出/巡演/开票** | 巡演 / 音乐会 / 开票 / 首演 / 剧场 / 演出 | 候选箱（kind=show）→ 人工补场馆/卡司 → `add_show.py` | 半自动 |
| **剧目/项目** | 剧 / 音乐剧 / 诗剧 | 候选箱（kind=activity）→ `dongyan_projects` / `activity_credits` | 半自动 |
| **物料** | 直拍 / 花絮 / 返图 / 后台 / 排练 | **不入库** | 跳过 |
| **其他** | — | 候选箱 | 人工 |

## 二、官方源的特殊处理

| 账号 | uid |
|---|---|
| 王晰本人 | 1292815744 |

- 官方源 **只对"新歌发行"自动落时间轴**；
- 官方源的演出/剧目仍进候选箱，因为需要场馆、场次、卡司等结构化字段，**不能靠一条微博猜**；
- 任何来源的物料类内容一律跳过。

## 三、去重与噪声

- 与 `timeline.json`、`intake_inbox.json` 标题前 12 字比对；
- 命中**已知作品名**（火光/长城长/草原之夜/沉响与长歌）视为旧事重提，不入箱；
- 噪声词（直拍/花絮/返图/转发/后台/排练/混剪）直接排除。

## 四、平台覆盖

| 平台 | 状态 |
|---|---|
| QQ音乐 | 自动（`watch_releases.py`） |
| 网易云音乐 | 自动（`watch_netease.py`） |
| 汽水音乐 | **不接入**（无公开 API，用户决定不啃） |

## 五、日常操作

```
python -X utf8 project_b\intake.py list          # 看待确认
python -X utf8 project_b\intake.py accept c00X   # 要
python -X utf8 project_b\intake.py reject c00X   # 不要
python -X utf8 project_b\intake.py done c00X     # 已手动入库
```

扫描由 `auto_update` 每日调用（`scan_intake.py --days 7`），**失败不阻断发布**。
