# 三个数据场景（修订稿：只保留证据能支持的话）

> 2026-11-03 修订｜删除机制判断、删除“全库最低”、删除“松/紧”状态词。
> 每篇仍是三块：**测量事实** / **可提的问题** / **不能说的**。

---

## 场景一：《南屏晚钟》

**测量事实**

| 指标 | 数值 |
|---|---|
| 音符密度 | 2.56 / 秒（全库中位 1.85） |
| C3 以下占比 | 35.6% |
| 音域跨度 | 2.02 八度 |
| 稳定度指标 | 6.7 音分 |

> **该曲在当前指标中同时呈现较高音符密度和较高 C3 以下占比。**

**可提的问题**
- 这首的密集是编曲给的，还是你要求把句子切碎？
- 低区占比这么高，你怎么保证字不糊？

**不能说的**
- 不能说“不是靠慢下来唱低”——密度不能证明演唱机制或实际速度。
- 不能说“35.6% 整首都处于低区”——它是占比，不是持续状态。
- 不能说低音在这首歌里“承担叙事”——没有歌词对齐。

## 场景二：《下沉》

**测量事实**

| 指标 | 数值 |
|---|---|
| 音符密度 | 1.08 / 秒（全库中位 1.85） |
| C3 以下占比 | 21.3% |
| 颤音幅度 | 104 音分（全库中位 81.5） |
| 稳定度指标 | 10.1 音分 |

> **两首低区作品在音符密度、颤音幅度和曲级稳定度指标上呈现不同组合，
> 提示低区作品可以有不同的旋律组织与 F0 形态。**

**可提的问题**
- 颤音放得更宽，是这首歌需要，还是录音时的状态？
- 稀疏的句子之间，你在想什么？

**不能说的**
- 不能写“少而松 / 多而紧”——那是把指标翻译成演唱状态。
- 不能说“两首放在一起证明低音不是一种唱法”——指标没有直接测量完整唱法。
- 不能说“更宽 = 更深情”。

---

## 场景三：《静止了的夜晚》

**测量事实**

| 指标 | 数值 |
|---|---|
| 已核目标段最低音 | **B1 61.5Hz**（当前正式发行版本） |
| 音符密度 | 2.21 / 秒（全库中位 1.85） |
| C3 以下占比 | 19.2% |
| 稳定度指标 | 9.3 音分 |

> **该曲当前正式发行版本的已核目标段记录为 B1（61.5Hz）。
> 在其他低值完成同口径复核前，不使用“全库最低”表述。**

**为什么仍值得写**：这是已核记录里最低的一档，且密度高于全库中位——
**两个可核事实同时出现**。

**可提的问题**
- 这个 B1 是旋律写的，还是你唱的版本把它压下去的？
- 现场唱到这里，你会不会改？

**不能说的**
- **不能说“全库最低”**：曲库还记录了《如翡》A1 55.2Hz、《梦开始的地方》A#1 58.3Hz、《无我》B1 60.1Hz，需同口径复核后才能比较。
- 不能说“不是慢歌托出来的”——密度不能证明。
- 不能说“是句子推进中掉下去的”——与“没有歌词/乐句时间轴”的边界冲突。

---

## 三篇共同边界

1. 只写**测量事实**与**可核对比**；
2. 不写“为什么”——那是访谈的活；
3. 不用未审计的句法结论；
4. 不做“全库之最”的断言，除非所有候选都同口径复核。
