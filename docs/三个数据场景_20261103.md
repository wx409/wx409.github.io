# 三个数据场景（初稿，只写有证据的部分）

> 2026-11-03｜每篇分三块：**测量事实** / **可提的问题** / **不能说的**。
> 不引用未审计的“低音在句中”，不写没有时间轴的“第几秒哪个字”。

---

## 场景一：《南屏晚钟》——密集的低音

**测量事实**

| 指标 | 数值 |
|---|---|
| 音符密度 | **2.56 / 秒** |
| C3 以下占比 | **35.6%** |
| 音域跨度 | 2.02 八度 |
| 稳定性 | 6.7 音分 |

**为什么值得写**：这是“密集 + 低区”同时成立的样本——**不是靠慢下来唱低，而是在密集的音符里保持低区。**

**可提的问题**（写进访谈清单）：
- 这首的密集是编曲给的，还是你要求把句子切碎？
- 在 35.6% 都低于 C3 的情况下，你怎么保证字不糊？

**不能说的**：
- 不能说“低音在这首歌里承担叙事”——没有歌词对齐，无法证明哪个字对应哪个音。
- 不能说“这是他的审美选择”——编曲与制作人因素未排除。

---

## 场景二：《下沉》——稀疏的另一种低

**测量事实**

| 指标 | 数值 |
|---|---|
| 音符密度 | **1.08 / 秒**（不到《南屏晚钟》的一半） |
| C3 以下占比 | 21.3% |
| 颤音幅度 | **104 音分**（全库偏宽，中位 81.5） |
| 稳定性 | 10.1 音分（全库偏松） |

**为什么值得写**：同样是低区作品，**这一首是“少而松”，《南屏晚钟》是“多而紧”**。两首放在一起，能证明“低音”不是一种唱法。

**可提的问题**：
- 颤音放得更宽，是这首歌需要，还是录音时的状态？
- 稀疏的句子之间，你在想什么（留白还是换气）？

**不能说的**：
- “更宽 = 更深情”——这是听感投射，没有证据。
- “稀疏 = 更高级”——价值判断，不是测量。

---

## 场景三：《静止了的夜晚》——全库最低的那一下

**测量事实**

| 指标 | 数值 |
|---|---|
| 最低稳定音 | **B1 61.5Hz**（全库最低，已复核） |
| 音符密度 | 2.21 / 秒 |
| C3 以下占比 | 19.2% |
| 稳定性 | 9.3 音分 |

**为什么值得写**：**全库最低音出现在一首中等密度的歌里**——不是慢歌托出来的，是句子推进中掉下去的。

**可提的问题**：
- 这个 B1 是旋律写的，还是你唱的版本把它压下去的？
- 现场唱到这里，你会不会改？

**不能说的**：
- 不能说“这个音是全曲情绪最低点”——情绪无法测量。
- 不能说“他每场都能唱到”——现场该音未过复核门槛。

---

## 三篇的共同边界

1. **只写测量事实与可验证的对比**；
2. **不写“为什么”**——那是访谈的活；
3. **不用未审计的句法结论**；
4. 每篇给编辑留一个“待访问题”，而不是替他回答。
