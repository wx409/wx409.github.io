# CALIBER.md — 三级读数制度 + 引用前检查清单

> 引用任何数字前读本文件。数字字典的机读版是 `data/calibers.json`（人读 `data/calibers.md`），
> 由 `project_b/build_calibers.py` 派生——**本文件是规则，那份表是数值**。

## 一、声学读数三级制度（全站统一，四页一致）

| 级别 | 定义 | 可否进标题/结论句 | 汇总计数 | 对外引用 |
|---|---|---|---|---|
| **稳定音（能力口径）** | 过复核门槛的最低音：该音符本身 **≥0.2s**、**HNR ≥5dB**、强度 **≥中位−25dB**，并经**原始混音谐波列**与/或 **CREPE** 交叉校验 | ✅ 可以 | ✅ 计入 | ✅ 可引用 |
| **触达音** | 实际到过的最低 F0，但未满足持续时长/复核门槛 | ❌ 不行 | ❌ 不进 | ❌ 不作能力依据 |
| **低音带读数** | 归属未完全确认（人声/乐器/念诵），如把 50–80Hz 单独带限后的中位值 | ❌ 不行 | ❌ 不进 | ❌ 仅供参考 |

**三不许（触达音与低音带读数）**：不进汇总、不进统计、不进对外引用句。

**A1 / A#1 / G#1 类读数**：目前全部未过复核门槛 → **不列、不提、不引用**。
它们只能作为「低音带读数（仅供参考）」出现在声乐实验区页面，且不得进标题、llms.txt、JSON-LD。

## 二、测量管线（口径的一部分）

```
音源（QQ音乐 320k / B站 / 央视网）
  → demucs htdemucs 人声分离（GPU；工程内 API + sphn 桩；HF_HUB_OFFLINE=1）
  → 自研 numpy YIN 逐帧 F0（fmin=55 / fmax=1100 / frame=2048 / hop=512 / sr=22050）
  → 音符切分（稳定段 ≥80ms、抖动 <0.6 半音）
  → 稳健过滤（时长 ≥0.15s、HNR ≥5dB、强度 ≥中位−25dB；极值音级需该音符本身 ≥0.2s）
  → 低音读数另做：原始混音谐波列判定（2f0/4f0 有峰＝真音；只有 3f0/6f0＝次谐波错误）
```

- **判基频必须用原始混音**：demucs 人声轨会削掉 60–90Hz 基频。
- 「双引擎一致」≠ 成立：缺基频刺激时 YIN 与 CREPE 会**同向误锁**。
- 混音版 53–57Hz 的 A1 是**伴奏 bass 污染**，只有人声分离后的 B1 及以上可信。

## 三、已知口径对照（易混，务必区分）

| 项目 | 口径 A | 口径 B | 说明 |
|---|---|---|---|
| B1 曲目数 | 跨素材精测层 **3 首** | 72 首录音室全量 **4 首** | 统计对象不同，**不可混读** |
| 巡演场次 | 巡演 **59 场** | 全站 **64 场**（= 巡演 59 + 签唱会 5） | 只有这一套正确口径；「60/65 场」已作废 |
| 指数年度值 | 追踪曲目池日均：2023=1013 / 2024=880 / 2025=862 / 2026=686 | 旧值 478/301/307/268 系千分位逗号缺陷 | 用 A 口径 |
| 指数覆盖天数 | 对外用**已发布长表的 1286 天** | 原始库文件 1271 天 | 差 11 天为补充来源 |
| 现场 vs 录音室 | 专辑层 vs 他人主导舞台：最低稳定音差异**不显著（p=0.197）** | — | 跨层读数不同是样本差异，不是矛盾 |
| 歌曲数 | 站内有多种计数（383 追踪池 / 588 元数据 / 748 档案 …） | — | **每个计数有独立范围，引用前查 `data/calibers.md`** |

**中位数纪律**：一律 `statistics.median`，禁止 `sorted(x)[len(x)//2]`（偶数样本会取上中位，
曾把跨度中位 2.30 算成 2.34）。同音名取曲按**实测 Hz** 排序。

## 四、引用前检查清单（逐条打勾）

1. [ ] 这个数字取自**哪个文件 / 哪个字段**？（能说出口径登记表里的 id 吗）
2. [ ] 它的**范围**是什么？（样本是 17 曲、72 曲、还是 383 首追踪池？）
3. [ ] 它是**稳定音**吗？如果不是，我是否写了限定词、并且没把它放进结论句？
4. [ ] 它是否与另一个范围的数字**被混用**了？（不同范围不是矛盾，混用才是错误）
5. [ ] 外部来源的读数，我**标注了出处与方法状态**吗？（方法未公开的一律标注）
6. [ ] 我用的措辞里有没有**过程稿用语**（旧口径/已作废/结论修正/瞬时最低）？
7. [ ] 这个数字需要**登记进 `build_calibers.py`** 吗？（新计数必须登记）

## 六、权威定性（外部原话，作档案记录，不作为本站结论）

## 七、口径分歧怎么处理（见 `debate/` 实验区）

外部来源（《乐器》杂志、粉丝扒谱）给出与本站不同的读数时：**不二选一，把分歧结构化**——
证据陈列（各带来源与方法状态）→ 双方标准 → 四种立场 → 按需引用的结论表述。
**外部读数永远不转写成本站测量结论。**
