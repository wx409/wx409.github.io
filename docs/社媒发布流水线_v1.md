# 社媒发布流水线 v1（双轨制 · 三色 · 五项出口）

> 一句话：**网站保存证据，社媒让人听懂，测量限制措辞能走多远。**
> 底线三句：**来源找得到，对象没测错，措辞没越界。**

## 一、双轨制

| 轨道 | 做什么 | 节奏 |
|---|---|---|
| **A 研究层**（网站） | 校准、敏感性、归属标注、机制讨论；允许几周，允许结论是"暂不能定" | 慢 |
| **B 发布层**（社媒） | 从一个已核个案出发，写一句人话结论 + 一个时间码 + 一句边界 | 快，不等 A |

**深度校准是网站可信度的建设，不是每条微博的发布前审批。**

## 二、三色：哪些能写

| 色 | 内容 | 要求 |
|---|---|---|
| 🟢 绿 | 有出处的引文、作品/场次事实、个人听感、已核时间码现象 | 标来源；听感写"我听到" |
| 🟡 黄 | 某个音的音级、两音距离、声部是否同时、同曲多场是否复现 | 四步最低核查（见下），措辞留边界 |
| 🔴 红 | 气息/气流/共鸣/声道等机制；"所有现场都没修音"；普遍排名；"别的男低音只能出声" | 研究完成前不写 |

**客观支撑不等于必须出现数字。** 一个带时间码的声部叠置、一条有出处的编曲引文、三个可点开的同曲现场，都能让文章有内容。

## 三、黄色内容：四步最低核查

1. **锁定素材**：场次、版本、时间码；不混用不同剪辑。
2. **确认归属**：目标段确实是他在唱；贝斯/伴唱/念诵分不清 → 不发这个数字。
3. **小范围复核**：换 2–3 组合理参数，或看原始混音谐波列（不必跑全网格）。
4. **按稳健程度落句**：
   - 换参数仍同音级 → "目标段约在 C2"
   - 音级稳、具体 Hz 漂 → 只写 C2，不写窄区间
   - 倍频/次谐波/归属摇摆 → 暂不发

跨场复现只写覆盖面：

> "在我核对过的三个现场里，同一目标段都落在 C2 音级。"

## 四、每条只带一个主证据

结构：**一个主问题 + 一个具体证据 + 最多一个主要数字 + 一句人话 + 一句边界 + 一个结论**

**模板 A · 单个目标音**
> 在〔场次〕〔时间码〕，这一目标段的读数落在〔音级〕附近。这里的重点是〔音乐意义〕。这个读数只针对该段素材，不代表整首歌的最低音。

**模板 B · 同曲复现**
> 我核对的〔N〕个现场里，同一目标段都落在〔音级〕。这说明至少在这些版本中他反复完成了同一个低音任务；不是说所有现场都完全一致。

**模板 C · 作品分析**
> 〔时间码〕开始，两条旋律出现叠置。〔媒体〕在报道中称之为"……"。我的听感是……。这段最值得听的是……。

## 五、发布出口（五项）

每个已测个案整理成：**可引用句 / 来源与时间码 / 测量对象 / 一句边界 / 状态与日期**。
存在 `data/publishable.json`，可引用句**只能从这里取**，不自行升级。

已有三个样板：

| 样板 | 可引用句 | 状态 |
|---|---|---|
| 《多听有益》C2 复现 | 我核对的五个现场里，同一段低音的读数都落在 C2 附近。 | 可发（措辞受限） |
| 百字明念诵段 | 这段念诵，速度大约是他平常说话的两倍。 | 可发 |
| 《静止了的夜晚》B1 | 最低稳定音 B1 61.5Hz，比 Low C 低一个半音。 | 可发 |

## 六、工具：发布前一条命令

```powershell
python -X utf8 project_b/publish_check.py --case P1-duoting-c2 --text "要发的文案"
```

- **RED**：全称断言（所有现场）、修音断言、机制解释（气息/共鸣/声道）、排名、越级证明 → **必须删改**
- **YELLOW**：C2/稳定/精确 Hz/音分 缺限定词 → 补边界
- **GREEN**：没命中红线（**只代表没越界，不代表内容正确**）
- 同时打印该 case 的引用原文、来源、对象、边界、状态

## 七、日常流程（5 步，约 10 分钟）

1. 从 `data/publishable.json` 选一个个案
2. 抄它的 `quote`，配一个时间码或一张图
3. 写一句人话结论 + 一句边界
4. 跑 `publish_check.py`，RED 清零、YELLOW 处理完
5. 发布

新复核改变结论时：改 `publishable.json` → 网页同步 → 必要时社媒补一条更正。
**自我修正不削弱可信度，它正是这套东西和宣传号的区别。**

## 八、与研究层的关系

- `data/claims.json` 决定"能说到哪一层"（M/S/主张类型）
- `data/publishable.json` 决定"这句能不能直接发"
- `publish_check.py` 决定"这条草稿有没有越界"

三层各管一段，**互不替代**：检查器不判断内容对不对，只判断措辞有没有超过证据。
