# 通知配置说明（微信推送 + 邮件，二选一或都用）

## 为什么用这个方案
- GitHub 通知在国内常被墙 → 不用
- Server酱（微信推送）与 QQ/163 邮箱在国内稳定可达 → 推荐

## 一、Server酱（推荐，免费，微信直达）

1. 打开 https://sct.ftqq.com/ （用 GitHub 或微信扫码登录）
2. 登录后进入「SendKey」页，复制形如 `SCT12345AbCdEf...` 的 SendKey
3. 关注「Server酱」微信公众号（扫码即关注）
4. 把 SendKey 填入下面配置文件

注意：免费版每天 5 条推送（本方案每天最多 2-3 条，足够）。

## 二、邮件（可选，双保险）

以 QQ 邮箱为例：
1. 登录 QQ 邮箱 → 设置 → 账户 → 开启「SMTP 服务」
2. 按提示获取「授权码」（16 位，不是 QQ 密码）
3. 填入配置文件

## 三、配置文件

路径：`E:\wx\私有工具\notify_config.json`（**敏感文件，永不进 git**）

```json
{
  "serverchan_key": "SCT12345AbCdEf...",
  "smtp": {
    "host": "smtp.qq.com",
    "port": 465,
    "user": "你的QQ号@qq.com",
    "password": "SMTP授权码",
    "to": ["你的QQ号@qq.com"]
  }
}
```
- 只填 serverchan_key 即可用微信通道；邮件可选
- 填好后测试：`python project_b/notify.py 测试 王晰数字档案通知测试`

## 四、会收到什么通知

| 事件 | 通知内容 |
|---|---|
| QQ新歌自动上架 | 🎵 歌名 + mid 清单（无需你操作） |
| 网易云新歌 | 🎵 歌名 + 专辑（无需你操作，diff 驱动） |
| 小酒馆新期次 | 🍷 期次名（无需你操作） |
| 全渠道聚合（Bing site:） | 📣 新增候选清单（需你确认） |
| 巡演候选（需人工确认） | 🎤 候选清单 + 确认命令（需你跑 confirm_event.py） |
| 自动更新成功 | ✅ 构建/发布/IndexNow 完成 |
| 自动更新失败 | ⚠️ 失败原因 + 处理建议 |

## 五、监测渠道总览（更新）：知道王晰发新歌的可靠途径

| 渠道 | 脚本 | 是否稳定 |
|---|---|---|
| QQ音乐搜索 | watch_releases.py | ✅ 稳定 |
| 网易云音乐 | watch_netease.py | ✅ 稳定（公开API） |
| Bing site: 定点聚合 | watch_web.py | ⚠️ 人名裸搜易被分词，仅 site:/锚点词可用 |
| 微博/小红书/抖音 | 无API，只能靠 Bing 索引或你订阅后丢链接 | ❌ 尽力而为 |
| ISRC 平台 | 无按歌手查询的公开接口 | ❌ 已暂停 |
| Apple Music/Spotify | 需密钥+代理，且王晰收录不全 | ⚠️ 可选 |

> 关键结论：国内歌手「发行新歌」的主阵地是 **QQ音乐 + 网易云**，二者可用公开接口稳定覆盖；
> 微博/小红书/抖音/ISRC 均无公开 API，只能靠「你订阅 → 丢链接给 AI 半自动入库」补位。

## 六、计划任务时间

- 触发：**每日 14:00 + 次日 00:05**（由 tools/install_auto_update_task.ps1 注册）
- 重装：双击 `tools/重装自动更新任务.bat`（建议右键"以管理员身份运行"）
