# 链接存档：把指定微博/报道存到本地

## 作用

把**不是王晰本人/工作室**的链接（俄通-塔斯社、新华网、外媒、公众号等）保存为本地快照，供日后核对、引用、做资料卡。

只存本地，不自动发布；版权归原媒体。

## 用法

```bat
cd /d D:\wx409.github.io

:: 微博
python -X utf8 project_b\archive_link.py "https://m.weibo.cn/status/5368380228895334" --name tass-shaman

:: 普通网页
python -X utf8 project_b\archive_link.py "https://www.news.cn/..." --name xinhua-chenxiang
```

## 存到哪里

```
E:\wx\私有工具\link_archive\YYYY-MM-DD\<name>\
├── meta.json      标题、URL、抓取时间、平台
├── text.md        正文纯文本
├── page.html      网页 HTML（非微博）
├── page.png       整页截图（非微博）
├── weibo.json     微博 API 原始 JSON
└── assets/        微博配图
```

## 平台差异

| 平台 | 方式 | 说明 |
|---|---|---|
| 微博 | `m.weibo.cn/statuses/show` + `wb.txt` cookie | 能拿到正文、作者、配图；不需要登录网页 |
| 新华网/普通网页 | Playwright 无头浏览器 | 保存 HTML、正文、整页截图 |
| 强反爬/需登录 | 可能只截到登录页 | 换用浏览器手动另存，或提供 cookie |

## 批量

```bat
for %u in (url1 url2 url3) do python -X utf8 project_b\archive_link.py "%u" --name auto
```

建议每条给 `--name`，否则用 URL 哈希命名。

## 引用规则

1. 本地存档只用于核对，不全文转载；
2. 站内引用只放短引文 + 原链接 + 快照日期；
3. 不把 `link_archive` 放进 git；
4. 外媒图片不直接搬，除非有授权。
