# 分析接入（GoatCounter，隐私友好）

站内不接广告、不做用户画像；分析只回答两件事：**哪页有人看、哪些外链被点**。

## 三步

1. 打开 https://www.goatcounter.com/ ，用邮箱注册一个免费站点（例如 `wx409`）。
2. 编辑 `data/analytics.json`：

```json
{"provider": "goatcounter", "site": "wx409"}
```

3. 重新注入并部署：

```bat
python -X utf8 project_b\inject_analytics.py
```

之后每个页面会加载：

```html
<script>window.__ANALYTICS__={site:"wx409"};</script>
<script src="/assets/analytics.js" defer></script>
```

## 会记录什么

- 页面访问（路径、来源、国家/地区；GoatCounter 默认不存 IP、不用 cookie）；
- 外链点击：`outbound/weibo.com`、`outbound/bilibili.com` 等；
- 不会记录：昵称、评论内容、表单内容。

## 没配置时

`site` 为空 → 不注入、不加载脚本、不发任何请求。  
`inject_analytics.py` 已接入部署流水线；填好 site 后，下次部署自动生效。
