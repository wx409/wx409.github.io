# 王晰的演唱特点：一份听得懂的科普

> 2026-10-28｜基于站内已核验的实测数据写；新一批现场录音（37 场 / 125 小时）正在分析，跑完后另出报告。
> 所有数字都有出处，不确定的标「待核」。

---

## 一、先搞清楚：男低音到底低在哪

| 声部 | 日常音域（约） | 参照 |
|---|---|---|
| 男高音 | C3–C5（131–523Hz） | 大部分人熟悉的男声 |
| 男中音 | A2–A4（110–440Hz） | 流行歌主力 |
| **男低音** | **E2–E4（82–330Hz）** | 低音声部下限 |
| **男低音（bass-baritone）** | 可下探到 C2 甚至更低 | 王晰在这里 |

**关键坐标：E2 = 82.4Hz，是男低音的"底线"。**

王晰的录音室实测最低稳定音是 **B1（61.5Hz）**——**比男低音的常规下限还低一个大三度**。

这就是"男低音稀有"的实际含义：不是"唱得低沉"，是**能稳定地唱到别人下不去的音**。

## 二、他的四个可量化特点

### 1. 低：61.5Hz 是硬指标

| 项目 | 数值 | 说明 |
|---|---|---|
| 录音室最低稳定音 | **B1 61.5Hz** | 《静止了的夜晚》，72 首全量实测 |
| 到 B1 的曲目 | **4 首** | 知晓 / 渔光曲 / 多听有益 / 静止了的夜晚 |
| 低音主区 | **B1–D2（61.5–75.5Hz）** | 全部低于 E2 |

> 为什么强调"稳定"：一次性蹭到低音不算能力；要满足**音符≥0.2 秒、谐波完整、HNR≥5dB**才算。

### 2. 稳：同一音符内只抖 7 音分

| 项目 | 数值 | 换算 |
|---|---|---|
| 音符内稳定性中位 | **7.25 音分** | 一个半音=100 音分，即**不到 1/13 个半音** |
| 含义 | 长音几乎不飘 | 这是"气息控制"的量化证据 |

**7 音分是什么概念**：普通人唱歌同一长音内抖动常在 20–50 音分；7 音分接近"仪器级"。

### 3. 颤：5.12Hz / 86 音分

| 项目 | 数值 |
|---|---|
| 颤音速率 | **5.12Hz**（每秒 5 次起伏） |
| 颤音幅度 | **86 音分**（接近一个半音） |
| 逐碟稳定性 | 4.95–5.34Hz（极差 0.27Hz） |

**听感翻译**：他的颤音是**慢而宽**的——不像美声那种快速抖动，更像大提琴的揉弦。这和他唱叙事性歌曲的语感匹配。

### 4. 跨度：2.23 个八度，且低区特别厚

| 项目 | 数值 |
|---|---|
| 跨度中位 | **2.23 八度**（72 首） |
| 高音稳定音 | F5 706Hz（《带着一颗好心去流浪》） |

**注意**：跨度不是他的卖点——2.23 八度在职业歌手里算中等。**他的稀缺性集中在低区密度**，不是音域宽度。

## 三、现场能不能复现？这是最关键的检验

录音室可以修音，现场不能。

| 检验 | 结果 |
|---|---|
| 现场素材总量 | **807 条 / 662 条过门槛 / 11 巡次** |
| 现场最低（已核） | **A#1 57.8Hz**（签售会自录，谐波列通过） |
| 特定低音段 C2 复现 | **五份素材均归入 C2（65.2Hz）** |
| 同曲跨场 | 《再见我的爱人》4 版极差 **0.14 半音** |
| 现场 vs 录音室差异 | **不显著（p=0.197）** |

**一句话**：他不是"只有棚里能唱"。

## 四、怎么听出这些特点（实用指南）

| 想听什么 | 听哪里 | 注意 |
|---|---|---|
| **低** | 《静止了的夜晚》《多听有益》主歌 | 耳机低频要好；手机外放听不出 60Hz |
| **稳** | 任意长音尾音 | 听它是否"抖成波浪" |
| **颤** | 副歌长音 | 数每秒起伏次数，约 5 次 |
| **共鸣** | 低音段 | 胸口/鼻腔的厚度，不是"音量大小" |
| **咬字** | 快歌 | 低音区还能听清字，是功夫 |

**避坑**：不要用"飙高音"评判他——他的赛道不在那儿。

## 五、我们怎么测的（为什么这些数字可信）

```
QQ音乐 320k / 现场录音
   → demucs 人声分离（开源模型）
   → 自研 YIN 逐帧测音高（每秒约 43 帧）
   → 音符切分 → 稳健过滤（时长/谐波/能量）
   → 三级读数：稳定音 / 触达音 / 低音带读数
```

**三级读数制度**（防止把"蹭到一下"当成"能唱"）：

| 级别 | 条件 | 能否引用 |
|---|---|---|
| 稳定音 | ≥0.2s、HNR≥5dB、谐波完整 | ✅ 可作能力结论 |
| 触达音 | 到过但没过门槛 | ⚠️ 只展示 |
| 低音带读数 | 归属未确认 | ❌ 不进统计 |

**双引擎交叉**：YIN 与 Praat 各跑一遍，一致率约 60%（40 段实验）。不一致时以谐波列人工裁决——**这正是为了不把算法错误写成他的能力**。

## 七、一句话总结

> **他的稀缺性不在"唱得高"，而在"低得下去、稳得住、颤得慢"**——
> 61.5Hz 的稳定音、7 音分的抖动、5Hz 的颤音，这三项放在一起，在流行男声里很少见。
