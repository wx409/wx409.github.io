# 直播 / 线上音源采集 SOP（VB-Cable 链路）

> 适用：线上演唱会、平台直播、电视台网络直播、只在客户端可播的独占内容。
> 不适用：现场（无线上流）——那种只能手机录，且低频基本不可用。
> 工具：`project_b/record_cable.py`、`project_b/loopback_selftest.py`、`project_b/audio_probe.py`、`tools/set_default_audio.ps1`

---

## 0. 一句话原则

**先自检、再开录；录完先体检、再进管线。**
没通过自检的录制，一律不进分析——否则会把"低频被砍"误读成"他没唱低"。

---

## 1. 事前检查（开播前 30 分钟）

| 项 | 检查方式 | 通过标准 |
|---|---|---|
| 虚拟声卡在位 | `pwsh -NoProfile -File tools\set_default_audio.ps1 -List` | 列表里有 `CABLE Input`；`-List -Record` 有 `CABLE Output` |
| 播放能否走 CABLE | 下面第 2 步的自检 | 60Hz/1200Hz 比 **|Δ| < 3 dB** |
| 磁盘空间 | 48k/24bit 立体声 ≈ **1.04 GB/小时** | 3 小时直播预留 ≥ 5 GB |
| 电源 | 接通电源，关闭睡眠 | 屏幕/睡眠不打断 |
| 通知音 | 关闭微信/QQ/系统提示音 | 避免混入 |
| 播放器 | 确认是"共享模式"输出（非 WASAPI 独占） | 独占模式会绕过 CABLE |

---

## 2. 开播前 5 分钟：链路自检（必须）

```powershell
cd D:\wx409.github.io
pwsh -NoProfile -File tools\set_default_audio.ps1 -Set "CABLE Input"
python -X utf8 project_b\loopback_selftest.py --device "CABLE Output (VB-Audio Virtual Cable)" --seconds 10
pwsh -NoProfile -File tools\set_default_audio.ps1 -Set "扬声器"
```

判据：

- **低频/高频 ≈ 0 dB**（实测 −0.1 dB）→ 通过，可以录
- **≤ −20 dB** → 不通过：查音效（Realtek 增强 / Nahimic）、查是否接错了设备
- 自检不过就不要开录，录了也是废片

> 自检会自己放测试音（60Hz + 1200Hz）、自己录、自己判，不需要人工听。

---

## 3. 开录

一条命令做完三件事：切默认输出 → 录 `CABLE Output` → 自动切回扬声器。

```powershell
cd D:\wx409.github.io
python -X utf8 project_b\record_cable.py --seconds 7200
```

- `--seconds` 按直播时长估：一首歌 300、半小时 1800、两小时 7200
- 输出：`E:\wx\论文素材_王晰作传\专辑\环回录制\cable_YYYYmmdd_HHMMSS.wav`
- **录制期间本机听不到声音**（声音进了虚拟线），这是正常的

**直播中途要注意：**

1. 不要改默认播放设备（会把音频切走）
2. 不要插拔耳机（端点重建，可能中断）
3. 直播分段（开场/中场/返场）可反复开录，文件名带时间戳即可
4. 若直播有"平台音量归一化/响度处理"，记下来——写进 meta 的 `platform_note`

## 4. 录后：先体检，再归档

### 4.1 体检（30 秒）

```powershell
python -X utf8 project_b\audio_probe.py "E:\wx\论文素材_王晰作传\专辑\环回录制\cable_20261024_180611.wav"
```

输出判据：

| 40–80 Hz 占比 | 判定 | 能做什么 |
|---|---|---|
| **≥ 15%** | ✅ 低频完整 | B1/C2 判定（仍须过谐波列） |
| 5%–15% | ⚠️ 低频衰减 | 只做中高音 / 稳定性 / 长音 |
| **< 5%** | ❌ 低频被砍 | 禁止用于低音结论 |

三个锚点（已实测）：母带环回 **21.6%**、320k **23.6%**、被音效污染 **0.00%**。

## 5. 进分析管线

### 5.1 单曲 / 整场测音

把裁剪后的 wav 放进一个"专辑目录"结构（`根/<组名>/<文件>.wav`），跑：

```powershell
cd "E:\wx\论文素材_王晰作传\音域分析"
python -X utf8 批量专辑音域.py --root "E:\wx\论文素材_王晰作传\专辑\环回录制_分析根" --albums "多听有益环回" --force
```

### 5.2 关键提醒：极值音以混音为准

demucs 人声轨会**削掉 60–90 Hz 基频**，低音区自动读数可能锁到高次谐波（实测把 61.6Hz 报成 246.1Hz = 4f0）。
所以：

1. 自动管线输出只当**候选**
2. 极值（最低/最高稳定音）必须过**原始混音谐波列**判定
3. 归属（是不是他唱的）必须人耳确认

### 5.3 场次层入库

整场直播若有明确场次，走「场次音域一键」：

```powershell
cd E:\wx\论文素材_王晰作传\音域分析\轨迹
python -X utf8 场次音域一键.py
```

## 6. 故障排查

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 录出来全是静音 | 默认输出没切成功 / 播放器走独占 | 重跑 `set_default_audio.ps1 -Set "CABLE Input"`；播放器改共享模式 |
| 低频 0%（自检 −50 dB） | 端点挂了音效（Nahimic/Realtek 增强） | 设备属性 → 高级 → 取消"启用音频增强"；或改用 CABLE（本 SOP 已绕开） |
| 录完扬声器没声音 | 默认输出没恢复 | `set_default_audio.ps1 -Set "扬声器"` |
| 文件异常小 | ffmpeg 被中断 / 设备占用 | 检查是否有别的程序占用 CABLE Output |
| 有爆音/断续 | 系统负载高、磁盘满 | 关掉其他占用、换磁盘 |
| 直播有平台音效 | 推流端处理 | 记进 `platform_note`，不影响判据但影响音色结论 |

1. 只用于**个人研究**，**不二次分发、不入库、不嵌入页面、不公开音频**
2. 对外只发布**方法与结果数据**（频率、时长、口径、证据等级）

4. 元信息里记录来源与时间，保证可追溯

## 8. 已知限制

- 环回经过系统混音：采样率可能被重采样（本机 48k），音量受系统音量影响
- 直播推流多为 128–320k AAC，**不是无损**；对 B1 判定够用（低频能量占比可与录音室对照），但不要写成"无损"
- 多人同台/合唱场次：极值音的**归属**仍不可判定，只能标"归属未定"
- 录制窗口要留足：按"曲目长度 + 60 秒"估算，宁可多录
