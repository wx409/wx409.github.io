## 三、新句内结果的使用边界

- 不进入分享/宣传出口；
- 不写“低音在句中/句尾”；
- 对外只写“待核观察”。

## 四、后续维护触发条件

只有以下三种情况才立即维护：

1. 发现**事实错误**；
2. 发现**样本错归**（如合唱被当独唱、现场被当录音室）；
3. **发布边界失效**（研究态结论进了宣传出口）。

其余探索性工作不阻塞、不承诺、不进主线。

## 六、发布边界（对外可用 / 不可用）

### 可用（已核，边界内）

> **在当前剔除已识别合作曲的 142 首作品中，117 首的曲级稳定度指标不超过 8 音分，占 82.4%。**
> 该指标的具体计算对象以指标字典为准，**不等同于现场稳定性、未经后期处理，也不构成相对其他歌手的优势**。

> **在当前 142 首独唱分类作品中，13 首的最低音名记录为 C2 及以下**（按 `low_hz ≤ 65.5` 计为 11 首）。
> 各曲的人声归属、稳定音等级与复核状态分别计算。

> **别只听王晰能唱多低，也看不同作品怎样使用低区。**

> **他的低音不是固定模板：不同作品的低区占比、旋律密度与颤音形态并不相同。**

### 不可用（发布不通过）

| 被拦下的说法 | 原因 |
|---|---|
| “84% 稳到 8 音分以内” | 用的是未剔除合唱的旧 155 首；且 8 音分 = **1/12.5 个半音**，不是 1/14 |
| “系统性 / 结构性优势” | 未排除修音、制作、曲目与段落选择 |
| “低音是稀缺资源 / 刻意控制使用” | 作品里的低区出现频次受旋律、定调、选曲与制作影响，不能推断本人动机 |
| “现场比录音室低 3 分贝、更暗但依然抓人” | 跨设备 dB 不可比；自动增益/PA/混音/母带均影响电平；“抓人”需观众反馈证据 |
| “最省、最稳的那个人” | 含跨歌手比较与主观定性，越出本曲库证据 |
