## 二、无法恢复的 40 个窗口

### 可恢复：现场混音 20 段（20/20）

`file` 字段是真实音频文件名（如 `一巡·Che_南京_03_BV1rt411K7wc_p3.wav`），
配合 `start_s` 可精确定位。

### 不可恢复：录音室人声轨 20 段（0/20）

`file` 字段存的是 **`htdemucs`**（路径倒数第二级目录名），**丢失了曲目/专辑名**。
20 条记录该字段全部相同，无法区分是哪首歌、哪个窗口。

复现尝试：按当时的 `glob → shuffle(seed=20261025)` 重建，得到的 `start_s` 序列
（111.0 / 97.0 / 87.5 / 200.5 …）与存档序列（137.5 / 137.5 / 192.5 / 180.0 …）**不一致**。
原因可能是文件集合变动或目录遍历顺序变化，**无法据此断定是同一批窗口**。
