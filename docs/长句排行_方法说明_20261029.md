# 最长连续发声排行 · 方法与素材说明（2026-10-29）

## 一、要回答什么

> 王晰现场最长的一口气能唱多久？五年里有没有变化？

"连续发声"定义为：**有声帧之间缺口 ≤0.2 秒**的连续段（换气会形成 >0.2 秒的静音缺口）。
这是"气息控制"的可量化指标，不涉及音高高低。

## 二、素材与取舍

| 素材 | 用途 | 说明 |
|---|---|---|
| 小卡带 37 场（853 曲） | **全量初筛** | 覆盖 2019–2024，每场完整歌单 |
| 录音笔 3 条（3w 设备等） | **高质量复核** | 音质显著更好（7099Hz vs 3211Hz、零削波），但只覆盖个别曲目 |
| 《想游泳的星》六轨人声 | **高质量复核** | 与录音笔同级，用于验证 15 秒长句 |
| Zoom H5 个人录音 | **未纳入** | 已在本机 D/E/F/G/H 盘按文件名与目录全盘检索，**未找到对应文件**；找到后可整场替换 |

**同曲去重规则**：同一场次同一首歌若有两个来源，取**音质更高**的那版（录音笔/六轨 > 两轨），
另一版不重复计数。

## 三、两阶段流程

1. **初筛（两轨人声轨 + CREPE）**：对 853 首逐曲找最长连续段，按 0.2 秒缺口判定；
2. **复核（六轨分离）**：初筛靠前的条目重新用 `htdemucs_6s` 分离，排除贝斯/低频伴奏造成的假连续。

> 两轨人声轨里可能混入贝斯，使"连续发声"被高估——所以**初筛结果一律标"待核"**，
> 只有六轨复核过的才进最终榜单。

## 五、局限

- 0.2 秒缺口阈值可能把快速换气当成连唱，需人工听辨复核长条目；
- 观众噪声、伴奏残留会影响有声判定；
- 不做跨歌手比较。
