## 一、三条纪律

1. 命令一律 `python -X utf8 ...`（防中文乱码）
2. 先 `cd` 到对应目录（下面每条都已写全）
3. `exit=0` 才算过；`exit=1` 看输出逐条修

## 二、发社媒

```bat
cd /d D:\wx409.github.io
python -X utf8 project_b\publish_check.py --text "你的整段话"
```

- `RED 0` → 可发
- `RED 1+` → 越界或数字错
- `YELLOW` → 建议补边界

## 七、页面速查

| 页面 | 干什么 |
|---|---|
| share | 发社媒取可引用句 |
| versions | 某首歌登记几版 / 纳入几版 / 能不能发 |
| stage | 某场演出有哪些素材 / 三态 |
| voice | 录音室音域：最低音、主区、B1 |
| skill | 能力维度：长音、颤音、稳定、跨度 |
| vocal | 总览与导航 |
| acoustic-report | 方法总站：校准、误差边界、快照 |

## 八、数字不敢用时的五问

4. 单场还是跨场？
