# 证据底句生成器 · 边界与封存说明

> 状态：**内部工具，已封存，不再扩展。**
> 定位：`数据更新 → 生成带来源与边界的证据底句 → 旧数字自动消失`。
> **不是**：宣传文案机器、口语生成器、比喻生成器。

## 一、它现在能做什么

- 从 `data/fact_atoms.json`（29 条事实）生成**单主张**证据底句（24 条）
- 每条底句携带：`fact_ids` / `claim_id` / `claim_version` / `snapshot_id` / `status` / `boundary` / `sources`
- 数据更新后重建，旧句子物理消失
- `verify_quotes.py` 回读校验：数字必须在事实池、主张必须可用、快照必填、**禁止多事实组合**

## 二、三个固定反例（永久保留，用于回归）

### 反例 1｜「登记 7 个版本」≠「唱过 7 次」

- ❌ 这首歌他唱过七次，五次能拿来比
- ✅ 目前登记《哭砂》的 7 个版本，其中 5 个纳入这项统计

原因：7 个版本可能包含同一场的不同上传或剪辑；「五次能拿来比」会被误读为另外两次唱得不行，实际只是未纳入当前统计。

### 反例 2｜模板不得偷换测量对象

- 事实：「目标段读数极差 = 8.88 半音」
- ❌ 模板输出：「最低音差出将近九个半音」

**数字 8.88 仍能在事实池里找到，但句子已经错了。** 这说明数字回读只能验证出处，不能验证指标、范围与推断有没有被替换。因此：**指标名必须原样保留，不得改写。**

### 反例 3｜半音不等于钢琴键

- 1 个半音 = 相邻两键的距离
- 8.88 半音 ≈ **9 个半音**，不能说成「八个键」
- 且「不同版本读数极差」与「一次演唱横跨的音域」是两回事

**结论：取消自动比喻，不再修补。**

## 三、两道闸门（已实现）

| 闸门 | 实现 |
|---|---|
| 主张与快照绑定 | 每条底句必须有 `claim_id` + `claim_version` + `snapshot_id`；主张非「可用」不生成；`verify_quotes` 校验 |
| 只做单主张装配 | `fact_ids` 长度必须为 1；多事实组合需来自已登记主张，当前不开放；候选/待核/排除事实不进入发布句 |

## 四、它不能做什么（明确不做）

- ❌ 不生成口语版、比喻版（数字回读发现不了语义错误）
- ❌ 不做多事实自由组合（两个正确的数拼一起可能产生未被证明的比较或因果）
- ❌ 不替代人写社媒叙述
- ❌ 不追求「事实数 × 模板数 = 无限句子」

## 五、正确分工

```
机器：生成准确的证据底句（可核查、可失效）
人  ：从底句里选一个有传播价值的问题，写最终叙述
检查器：阻止越界（publish_check）
```

## 六、封存

本工具到此为止。后续若要扩展，只允许：
1. 新增**事实类型**（必须能绑主张、有快照）
2. 新增**单事实模板**（不得改写指标名）

不再新增：多事实组合、口语变体、比喻、评分式措辞。

主线回到 `voice` 页迁移。
