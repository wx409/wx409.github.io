# 声学页面升级方案 v1（2026-10-24）

> 目标：让全站声学页 **更科学（经得起推敲）· 更清楚（不做声乐课也看得懂）· 更能转发（同担愿意发）**。
> 起因：现在的数字“不明觉厉”——看得出很厉害，但说不出厉害在哪，也没法转给不懂声学的人。

## 一、诊断：三个具体病

| 病 | 例子（现页面） | 后果 |
|---|---|---|
| **数字没有参照系** | “音符内稳定性中位 7.25 音分” | 读者不知道 7.25 是好还是差 |
| **术语没有入口** | HNR 5.9dB、12-TET 偏差 9.25 音分、频谱质心比 0.996 | 一眼劝退，无法转述 |
| **结论没有一句话** | 表格很长，但没有一句能直接复制发出去的话 | 想分享只能截图，看不懂图 |

## 二、三层改法

### A 层 · 科学性（每处数字配"四件套"）

1. **定义**：这个指标物理上是什么（一句话）
2. **口径**：怎么测的、样本量、门槛（已经比较全，缺统一展示）
3. **参照系**：与什么比（行业下限 / 常规区间 / 他本人其他作品）
4. **局限**：这个数字不能推出什么（**这一条最缺，也最能建立信任**）

并补两个新的科学模块：

- **敏感性分析**：同一结论换参数再跑一次（LPC 阶数、max formant、平滑窗），给出漂移范围；漂移大就标"不宜作为结论"
- **没测清单（Negative list）**：明确写出"我们没测什么"——声门闭合度、气流、共振峰（本轮失败）、音色主观评价

### B 层 · 可读性（每个数字配"三句话"）

- **参照**：比男低音常用下限 E2（82.4Hz）低 4 个半音
- **判读**：在已测曲目中处于最低一档
- **人话**：钢琴上相邻两个键的二十分之一

再加两个固定组件：

- **术语词典**：`<details>` 折叠，鼠标点开才出现解释，不打断阅读
- **结论先行**：每页顶部 3 条，每条 ≤ 20 字

### C 层 · 可分享性

- 每个结论后附 **可引用句**（带证据等级徽章：✅已核验 / 🟡已取证 / ⏳待判 / ❌归属未定）
- 页面底部 **“可以直接抄走的三句话”** 区块
- 现有分享图/长图继续用，但每张图只回答一个问题

## 四、判读标准的来源（避免自说自话）

| 指标 | 参照系来源 |
|---|---|
| 男低音下限 E2 82.4Hz、Low C C2 65.4Hz | 合唱写作/声乐教学通行标注（已在 `data/calibers.md`） |
| 音分（100 音分=半音） | 十二平均律定义 |
| 颤音 4–8Hz、20–150 音分 | Sundberg (1987)；Titze (1994) |
| 人耳音高辨别阈值 ≈10 音分 | 心理声学通行量级（引用时注明为近似值） |
| 共振峰与谐波耦合 | Sundberg (1987)；Bozeman (2013)（注意适用条件，见 `docs/共振峰实测_三法对照_20261024.md`） |

## 五、验收标准（每页改完必须满足）

1. 页面顶部有 **3 条结论先行**，每条 ≤ 20 字
2. 每个数字都有 **参照系 + 判读 + 人话** 三者
3. 每个数字都有 **证据等级徽章**
4. 有 **术语折叠**，不打断正文
5. 有 **“可以直接抄走的三句话”**
6. `audit_caliber` / `audit_jsonld` / `audit_nav` 全绿
