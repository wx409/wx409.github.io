# 朗读声学对比：王晰 vs 同节目两位朗读者（2026-11-20）

> 目的：回答“阅读类素材是否更好分析、王晰的朗读与别人比突出在哪”。
> 素材：喜马拉雅《我们的好梦时刻》同专辑、同后期（含 BGM）的三期——
> 王晰（13:05）、阿云嘎（5:02）、王鸥（13:10）。
> 方法：ffmpeg 转 44.1k → demucs htdemucs 取 vocals → CREPE（16k，fmin 60/fmax 400，
> periodicity>0.6）取 F0；RMS 取停顿/动态；Whisper 转写取字数。

## 结果

| 指标 | 王晰 | 阿云嘎 | 王鸥 |
|---|---|---|---|
| F0 中位 | **83.0 Hz** | 145.8 Hz | 189.1 Hz |
| F0 p10–p90 | 63.7–259.8 | 100.1–220.7 | 151.9–240.7 |
| 音域跨度（p10–p90） | **2.03 八度** | 1.14 八度 | 0.66 八度 |
| 音高四分位距（半音） | **10.2** | 7.7 | 4.5 |
| 有声帧占比 | 0.213 | 0.238 | 0.419 |
| 字数 / 分钟 | **131** | 138 | 157 |
| HNR 中位 | 7.8 dB | 8.6 dB | 10.8 dB |
| 有声段动态范围（p95−p5） | 22.7 dB | 34.3 dB | 23.6 dB |

## 三个可说的差异

1. **音高最低**：中位 83 Hz（≈E2），比阿云嘎低约 9.7 个半音，比王鸥低约 14.2 个半音。
   这是“男低音朗读”最直观的听感来源，但 83 Hz 已接近说话声的极低端，需人耳复核是否含低频 creak/次谐波。
2. **音高起伏最大**：IQR 10.2 半音（阿云嘎 7.7、王鸥 4.5），跨度 2.03 八度。
   听感上更像“演读”而不是平铺直叙——句内高低差明显，情绪推动强。
3. **语速最慢、停顿最多**：131 字/分（阿云嘎 138、王鸥 157）；有声帧占比最低（0.213），
   停顿更密。合起来是“慢、留白、压低”的朗读策略。

HNR 7.8 dB 略低于两位对照，提示气声/低频粗糙成分更多；这项受分离与 BGM 影响大，只作参考。

## 方法局限（必须一起写）

- 三篇文本不同、时长差一倍（阿云嘎 5 分钟），**不是严格对照实验**；
- BGM 与 demucs 分离对语音不是专用模型，F0 极值（尤其 259.8 Hz）可能混入伴奏/齿音；
- 字数为 Whisper 转写计数，非逐字校对；
- 结论只适用于“这一期朗读”，不能外推成“他的朗读能力上限”。
