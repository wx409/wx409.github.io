# 证据升级 v2：先校准，再测量；先限定结论，再选指标

> v1 只做了“表达装修”。v2 按证据链重排：**声音产生 → 录音与后期 → 人声归属 → 参数估计 → 误差与稳健性 → 对照设计 → 声乐解释 → 对外表述**。
> 任何一环断裂，后面的结论自动降级。

## 一、v1 的四处错误（已废）

| v1 说法 | 错在哪 |
|---|---|
| 每个数字都要“参照＋判读＋人话” | 会逼着编辑给描述性事实强加价值判断，把研究页写回宣传页 |
| “5 音分 < 10 音分人耳阈值” | 10 音分不是固定门槛；且管线误差未校准，读数差 ≠ 实际波动 |
| “F1 是否落在 61.7Hz 附近” | F1 是共振峰、H1 是基频谐波，二者不是一回事；出现“F1≈62Hz”应先怀疑误把 H1 当 F1 |
| 用 Bozeman 一句话开测 | 他的结论是**待验证的机制假设**，且有声部/元音/音高/教学语境前提 |

## 二、分级体系（三个字段，不再用单轴排高低）

### 1. 校准集：`project_b/calibrate_pitch.py` → `data/calibration_pitch.json`

用**已知答案**的合成谐波复音，量出音高管线“错了会错多少”：

| 结果 | 数值 |
|---|---|
| 设计 | 4 个音高 × 5 种条件 × 3 个随机种子 × 2 种时长 = **120 次运行** |
| 判对 | **120 / 120**（容差 ±50 音分） |
| 绝对误差·中位 | **3.4 音分** |
| 绝对误差·P90 / 最大 | **9.2 / 12.4 音分** |

**它立刻改变了一句话的写法**（注意：中位数与最大值不能拼成“3–9 音分”这种区间）：

> 原写法：“五场只差 5 音分，比人耳能分辨的还小。”
> 校准后：“五场**读数**集中在 65.2–65.4Hz，读数差约 5 音分。在 120 次合成信号测试中，音高绝对误差中位 3.4 音分、最大 12.4 音分；**真实现场素材的误差尚未估计**。因此 5 音分只作为**读数差**报告，不解释为歌手实际音高波动。”

**已知局限**：合成信号无颤音、无辅音、无元音变化，只覆盖“音高提取”这一环；真实素材上的次谐波/倍频错误另有来源，需第二层校准（真实录音 + 人工逐帧标注）。

### 2. 主张登记册：`data/claims.json`

基本单位从“指标”改成“主张”，每条含：层级 / 素材 / 归属依据 / 定义 / 算法 / 校准 / 敏感性 / 可比性 / 可以写 / 不可以写 / 失效条件 / 复核人。

首批三条，正好代表三种难度：

| 主张 | 测量可信度 | 推断范围 | 状态 |
|---|---|---|---|
| C1《多听有益》五份素材读数集中在 C2 | **M1**（最弱环节） | S2 | ✅ 可用（表述受限） |
| C2《静止了的夜晚》B1 61.5Hz | M2 | S1 | ✅ 可用 |
| C3“低音提亮＝F1/F2 托 1fo” | M0 | 机制型 | ⏸ **暂停** |

### 3. 分级体系（替代原来的 ✅/🟡）

- **M0–M2**：归属与测量可信度
- **推断范围 S1–S4**：单个片段 → 同曲多版本 → 某类演出/某轮巡演 → 整体能力
- **主张类型**：描述 / 复现 / 比较 / 机制 / 评价（与推断范围**分开**，不再用一条刻度把“跨歌手比较”和“机制解释”强行排高低）

一条“C2 复现”＝复现型 + S2；一条“亮度机制”＝机制型 + 需要机制证据，**不能因为前者成立就顺带获得**。

> 注：C1 整批按**最弱环节**定为 M1（上海、杭州仅有谐波列复核，未人耳确认），不标 M2。

## 三、止损清单（第一阶段，立即执行）

| 停用 | 原因 |
|---|---|
| “低音提亮＝F1/F2 托住 1fo” | 不同共振峰估计方法结果不一致，当前素材与参数不足以稳定估计 F1/F2；不据此解释声道机制（F1 高于 F0 并不反常，也不能推翻声源—滤波器机制） |
| “10 音分人耳阈值”类收尾 | 非固定门槛，且未校准 |
| “实际只波动 5 音分” | 真实素材误差未估；5 音分只是**读数差** |
| “气流更大/更费气” | 无本站证据 |
| 任何跨歌手排名 | 无可比对照 |

## 四、页面结构（替代“每条都判读为厉害”）

1. 本页回答什么问题
2. 目前能确认什么
3. 最关键的一段原声或一张图
4. 数字是什么意思
5. 证据怎样取得
6. 换参数是否仍成立
7. **不能由此推出什么**
8. 可分享结论 + 适用范围
9. 原始数据、方法版本、修订记录

**允许写“目前只能描述，不能判优劣”。**
